## 二、传感器模块

### 2.1 温湿度传感器 DHT22

**型号**：DHT22（AM2302）
- **接口**：单总线（Digital）
- **精度**：
  - 温度：±0.5°C
  - 湿度：±2%RH
- **量程**：
  - 温度：-40~80°C
  - 湿度：0~100%RH
- **供电**：3.3V-5V
- **价格**：6-8元/个
- **数量**：3个（上、中、下三点监测）
- **推荐店铺**：搜索"DHT22 温湿度传感器 AM2302"
- **注意事项**：
  - 单总线通信，需要上拉电阻（通常模块已内置）
  - 读取间隔建议≥2秒
  - 避免在强风或阳光直射环境下使用

**连接方式**：
```
DHT22模块    →    STM32F407VGT6
VCC         →     3.3V或5V
GND         →     GND
DATA        →     PA0/PA1/PA2 (GPIO输入，单总线)
```

### 2.2 光照传感器 BH1750

**型号**：BH1750FVI
- **接口**：I2C
- **量程**：0-65535 lux
- **精度**：±20%
- **供电**：3.3V-5V
- **价格**：3-5元/个
- **数量**：1个
- **推荐店铺**：搜索"BH1750 光照传感器 I2C"

**连接方式**：

SCL         →     PB6 (I2C1_SCL)

### 2.3 人体感应传感器 HC-SR505

**型号**：HC-SR505（迷你小型）
- **类型**：红外人体感应
- **检测距离**：3-5米（固定）
- **检测角度**：≤120°
- **输出**：数字信号（高/低电平）
- **供电**：5V（推荐5V）
- **延时时间**：3-5秒（固定）
- **价格**：2-3元/个
- **数量**：1个
- **推荐店铺**：搜索"HC-SR505 迷你小型人体感应模块"
- **优点**：
  - 尺寸小，安装方便
  - 价格更低
  - 使用简单，无需调节
  - 固定延时满足衣柜照明需求

**连接方式**：
```
HC-SR505模块  →    STM32F407VGT6
VCC          →     5V
GND          →     GND
OUT          →     PC0 (GPIO输入)
```

## 十一、选型注意事项

### 11.1 电源要求

- **ESP8266**：必须3.3V，不能接5V
- **DHT22**：3.3V或5V都可以
- **串口屏**：通常需要5V
- **风扇、LED**：12V或5V，根据型号选择

### 11.2 接口匹配

- **SPI接口**：RFID、Flash共用SPI总线，注意CS片选
- **I2C接口**：光照传感器、RTC等可共用I2C总线
- **UART接口**：串口屏、WiFi、语音模块各用独立UART

### 11.3 功率计算

- **总功率**：约200-250W（最大）
- **12V电源**：需要≥5A（60W）
- **5V电源**：需要≥3A（15W）
- **3.3V电源**：需要≥1A（3.3W）

### 11.4 散热要求

- **UVC LED**：需要散热片
- **红外LED**：需要散热片+风扇
- **除湿片**：需要散热片+风扇

## 十四、总结

器件选型要点：
1. **电源匹配**：注意各器件的供电电压
2. **接口匹配**：SPI、I2C、UART接口分配
3. **功率计算**：确保电源足够
4. **成本控制**：核心功能优先，可选功能后续添加
5. **质量保证**：选择信誉好的店铺，注意评价
