# 智能衣橱申报书电控部分内容

可直接用于申报书“技术方案 / 电控系统 / 硬件控制”栏目。

## 一、电控系统总体任务与分层架构

本项目电控系统负责将上层取衣、放衣、识别、清理和护理任务转化为安全、连续、可反馈的机械动作。系统采用“上层任务输入 + STM32F407主板1调度 + STM32F407主板2执行 + 机构状态反馈”的分层控制架构，使人机交互、任务调度和底层运动控制相互解耦。

在该架构下，树莓派触摸屏网页、App/Web或云端后端只表达任务意图，不直接输出电机脉冲；主板1负责接收任务、汇聚传感器状态、判断执行条件并下发动作命令；主板2负责多轴步进电机、舵机、夹爪、伸缩轴、B区毛刷、C区热风、负离子和通风风扇等执行机构控制。

| 层级 | 组成 | 作用 |
| --- | --- | --- |
| 任务输入层 | 触摸屏网页、App/Web、云端后端 | 产生取衣、放衣、识别、清理、护理和急停等任务意图。 |
| 调度控制层 | STM32F407主板1 | 负责指令接收、状态判定、任务调度、异常拦截和板间命令转发。 |
| 运动执行层 | STM32F407主板2 | 负责多轴运动、夹爪舵机、伸缩机构、毛刷和护理组件执行。 |
| 状态反馈层 | 限位、温湿度、重力、按键、到位反馈 | 提供执行前校验、动作完成判断、异常保护和任务状态回写依据。 |

## 二、任务指令流转与调度机制

电控系统不是直接根据按钮让单个电机动作，而是先将上层任务转化为可执行的电控流程。主板1接收到任务后，先判断目标挂位、机构状态、环境状态和急停状态是否满足执行条件，再将任务拆解为主板2可以执行的动作命令。

这种任务流转机制使上层页面、云端任务和底层机构之间形成清晰边界：上层只负责“要做什么”，主板1负责“能不能做、按什么顺序做”，主板2负责“具体怎么动、是否到位”。

| 任务类型 | 主板1调度重点 | 主板2执行重点 |
| --- | --- | --- |
| 放衣/入库 | 确认流程状态，选择A区取衣点与目标C区存放点。 | 驱动夹爪、伸缩轴和X/Y/Z轴完成转运。 |
| 取衣/输出 | 确认目标挂位状态，组织从C区到A区的取衣路径。 | 经过前置点和中转点完成夹取、转运和释放。 |
| 拍照/识别 | 在到达B0识别点后触发拍照或识别任务。 | 将夹爪移动到识别位置并保持稳定姿态。 |
| 清理/护理 | 根据任务类型选择B区毛刷或C区护理组件。 | 控制毛刷、热风、负离子和风扇按设定流程执行。 |
| 急停/异常 | 最高优先级拦截当前流程并下发停止指令。 | 停止运动输出，避免机构继续执行危险动作。 |

## 三、点位表路径规划、防干涉与轨迹控制

衣橱内部空间紧凑，夹爪、衣物、挂位、毛刷和护理组件之间存在潜在干涉风险。因此，系统将A区、B区、B0识别点、C区、回家点和前置点抽象为功能点位表，并根据不同任务自动选择运动路径。

路径规划过程中，程序优先抬升Z轴到安全高度，再进行X/Y平面移动，最后下降进入目标点；进入A区和C区等狭窄区域时，系统先经过前置点和中转点，再进入真实目标点，避免低高度横移、直接斜插和未达到安全姿态前的翻转动作。该设计可概括为“电子围栏式防干涉路径控制”。

在平面运动控制上，X轴和Y轴并不是两个互不相关的独立动作，而是共同决定夹爪在衣橱内部的运动轨迹。如果两轴采用相近速度直接运动，位移较短的轴会提前到位并停止，后续只剩另一轴继续运动，实际轨迹会由平滑斜线变为折线路径，容易造成运动方向突变和衣物姿态晃动。

因此，系统在点位表路径规划基础上引入X/Y双轴同步到点策略。程序先计算两轴目标位移差异，再根据预计运行时间对速度、加速度和启动时序进行协调，使两轴尽量同步到达目标点。该策略与安全高度、前置点、中转点共同构成电控层的防干涉与轨迹平稳控制机制。

| 路径控制策略 | 具体含义 | 展示价值 |
| --- | --- | --- |
| 功能点位表 | 将A区、B区、B0、C区等位置统一建模。 | 说明机构运动有目标点和任务语义，不是盲目移动。 |
| 安全高度优先 | 先抬Z轴，再进行X/Y移动，最后下降。 | 降低夹爪、衣物与柜体结构发生干涉的风险。 |
| 前置点进入 | 进入A区、C区前先经过偏移位置。 | 避免直接切入狭窄区域，提高动作可控性。 |
| B点中转 | A区与B0、C区与A区之间设置过渡路径。 | 减少斜插路线和姿态未调整前的危险运动。 |
| X/Y同步到点 | 根据两轴位移差异协调速度或启动时序。 | 减少折线路径和方向突变，使夹爪轨迹更连续。 |

## 四、表驱动动作状态机与多机构协同

主板2的执行逻辑采用表驱动动作状态机，将复杂任务拆解为移动、等待、夹取、释放、翻转、伸缩、清理和护理等标准动作单元。每一步动作完成后再进入下一状态，使整套流程具备明确顺序、可等待、可中断、可扩展的特点。

在该机制下，夹爪、舵机、伸缩轴、B区毛刷、C区热风机、负离子发生器和通风风扇不再是分散控制，而是被纳入统一动作链路。后续如果增加挂位、调整路径或扩展护理动作，可以优先调整点位参数、等待时间和动作表，而不是重写整套控制逻辑。

| 动作单元 | 控制对象 | 作用 |
| --- | --- | --- |
| 移动到点位 | X/Y/Z轴、伸缩轴 | 完成夹爪或衣物在功能区之间的定位。 |
| 夹取与释放 | 夹爪舵机、Z轴 | 完成衣物抓取、放置和输出动作。 |
| 姿态调整 | 舵机、Z轴安全高度 | 在允许高度内完成翻转或姿态切换。 |
| 清理动作 | B区毛刷、步进电机、舵机 | 完成衣物表面毛发、浮尘和附着物清理。 |
| 护理动作 | 热风、负离子、通风风扇 | 完成烘干、除味、散湿和空气流通辅助。 |

## 五、典型任务闭环流程

电控系统围绕放衣、取衣、拍照识别、B区清理和C区护理等典型任务建立闭环流程。每类任务都不是单步动作，而是由主板1先进行任务解析和状态判定，再由主板2按照动作表执行多阶段动作，最后将完成状态或异常状态反馈给上层系统。

放衣流程从A区取衣，经过B/B0识别点后进入C区存放；取衣流程从C区目标挂位出发，经过前置点和B点中转后回到A区输出；清理和护理流程则由主板1根据任务类型调度主板2执行毛刷、热风、负离子和通风风扇动作。通过任务闭环设计，电控系统能够把“用户点击”转化为可验证、可反馈的机械执行结果。

| 典型任务 | 闭环流程 | 反馈结果 |
| --- | --- | --- |
| 放衣/入库 | A区夹取 -> B/B0识别 -> C区存放。 | 衣物进入目标挂位，状态可回写。 |
| 取衣/输出 | C区目标挂位 -> 前置点 -> B点中转 -> A区输出。 | 衣物送达用户取衣位置。 |
| 拍照/识别 | 移动至B0识别点 -> 姿态保持 -> 触发拍照或识别。 | 获得图片或识别结果。 |
| 清理任务 | 转运至B区 -> 毛刷接近 -> 清理动作循环。 | 完成表面清理并返回状态。 |
| 护理任务 | 转运至C区 -> 热风/负离子/通风组件执行。 | 完成烘干、除味或通风辅助。 |

## 六、安全保护与异常处理机制

安全可靠性设计贯穿任务执行全过程。系统通过挂位限位、温湿度、重力、本地按键、到位反馈和动作超时等状态量进行执行前校验、执行中监测和异常停止。急停命令具有最高优先级，动作超时或状态异常时应停止当前流程并回到安全状态。

该安全机制分为三层：执行前确认任务类型、目标挂位和传感器状态；执行中持续等待到位反馈并进行超时判断；异常发生后停止当前动作，避免机构继续运动造成夹持失败、碰撞或衣物损伤。

| 保护环节 | 说明 |
| --- | --- |
| 执行前校验 | 检查任务类型、目标挂位、机构状态和必要传感器条件。 |
| 执行中监测 | 等待电机到位反馈，结合超时机制判断动作是否可靠完成。 |
| 异常停止 | 急停、动作超时或状态异常时停止执行，避免机构继续动作。 |
| 状态回写 | 将完成、失败或异常状态反馈给上层页面或云端任务。 |
| 安全恢复 | 异常后优先进入待机或安全位置，再等待人工确认或重新调度。 |

## 七、电控系统创新点与可展示成果

本项目电控部分的价值不只在于驱动电机动作，而在于形成了较完整的“任务调度、路径约束、状态机执行、安全反馈”一体化控制方案。它能够支撑自动取放衣、识别、清理和护理等功能，并为后续增加挂位、护理动作和更多异常反馈提供扩展基础。

从申报书和答辩展示角度看，电控系统可突出以下成果：双STM32F407分层控制架构、点位表路径规划、防干涉路径控制、X/Y同步轨迹控制、表驱动动作状态机、多机构协同执行和多源状态安全保护。这些内容既能体现硬件控制工作量，也能体现项目从“能动”到“稳定、安全、可扩展地动”的工程化提升。

| 展示/创新项 | 体现价值 |
| --- | --- |
| 双主板分层控制 | 将任务调度和运动执行解耦，降低系统复杂度。 |
| 点位表路径规划 | 让A区、B区、B0、C区等位置具备统一任务语义。 |
| 防干涉与同步轨迹 | 提升夹爪在狭小空间内转运衣物的稳定性和安全性。 |
| 表驱动动作状态机 | 便于扩展放衣、取衣、识别、清理、护理等动作流程。 |
| 多源安全反馈 | 通过限位、温湿度、重力、按键、到位和超时机制提高可靠性。 |
| 可展示材料 | 可形成电控架构图、路径规划图、状态机图、任务闭环图、安全保护图和测试记录。 |

综上，电控系统并不是简单驱动电机动作，而是通过双主板分层架构，将上层任务转化为带路径规划、防干涉约束、状态机编排、双轴同步控制和安全反馈的完整机械执行流程，为智能衣橱实现自动取放衣、识别、清理和护理提供稳定的底层控制基础。
