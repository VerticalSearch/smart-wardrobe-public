# 智能晾衣架系统设计方案

## 一、项目概述

### 1.1 核心价值：解决用户真实痛点

**用户痛点**：
- ❌ **阴雨天无法晾干**：连续阴雨天，衣服晾不干，发霉有异味
- ❌ **晾晒时间太长**：正常晾晒需要1-2天，甚至更久
- ❌ **晾晒效果不好**：衣服干了但硬邦邦，不柔软
- ❌ **卫生问题**：室外晾晒有灰尘、细菌

**解决方案**：
- ✅ **快速晾干**：1-2小时完成（比传统快10-20倍）
- ✅ **不受天气影响**：阴雨天也能快速晾干
- ✅ **保持柔软**：低温风干，不伤衣物
- ✅ **干净卫生**：室内风干+紫外线消毒

### 1.2 核心功能

**智能快速晾干系统**：自动将衣物进行热风循环风干和紫外线消毒，1-2小时快速完成。

### 1.3 工作流程（完整方案）

**双模式智能晾衣架系统**：

**模式1：自然晾晒**（晴天）
```
用户挂衣服 → 系统检测天气 → 晴天 → 步进电机移到室外晾晒区 → 自然晾晒
```

**模式2：热风烘干**（阴雨天）
```
用户挂衣服 → 系统检测天气 → 阴雨天 → 留在室内风干区 → 热风烘干 → AI判断完成
```

**AI智能判断**：
- 重量传感器持续监测
- AI分析重量变化趋势曲线
- 判断是否干燥，自动完成
- 多衣服：独立控制每个位置的风力

**模式选择**：
- **自动模式**：根据天气API自动选择（推荐）
- **手动模式**：用户手动选择
  - 快速模式：1-2小时，高温+强风（适合急需）
  - 标准模式：2-4小时，中温+中风（适合日常）
  - 轻柔模式：4-6小时，低温+弱风（适合精细衣物）
  - 消毒模式：风干+UV-C消毒（适合特殊需求）

### 1.4 用户使用场景

**场景1：阴雨天急需衣服**
- 问题：连续阴雨天，衣服晾不干，明天要穿
- 解决：选择"快速模式"，1-2小时完成
- 价值：解决了阴雨天无法晾干的痛点

**场景2：日常快速晾干**
- 问题：洗完衣服，想快速晾干
- 解决：选择"标准模式"，2-4小时完成
- 价值：比传统晾晒快很多

**场景3：精细衣物保护**
- 问题：丝绸、羊毛等精细衣物，需要轻柔处理
- 解决：选择"轻柔模式"，4-6小时完成
- 价值：保护衣物，保持柔软

**场景4：消毒需求**
- 问题：衣服有异味，需要消毒
- 解决：选择"消毒模式"，风干+UV-C消毒
- 价值：保证卫生

## 二、硬件需求分析

### 2.1 步进电机系统

**需求**：2个45步进电机，控制丝杠运动

**功能**：
- 电机1：控制晾晒区到风干区的水平移动
- 电机2：控制衣架在风干区的垂直移动（或辅助定位）

**选型思路**：
- **45步进电机**：扭矩适中，适合丝杠传动
- **丝杠规格**：根据移动距离选择（如1605、2005等）
- **驱动模块**：A4988或DRV8825步进电机驱动
- **限位开关**：检测起始和终止位置，保证定位准确

**控制思路**：
- 使用步进电机精确定位
- 通过限位开关校准位置
- 记录每个衣架的位置坐标
- 实现往返运动控制

### 2.2 风机系统

**需求**：4-5个风扇，带电阻丝加热，支持独立控制

**功能**：
- 提供风力循环，加速衣物风干
- 电阻丝加热，提高温度，降低相对湿度
- 多风扇协同工作，保证气流均匀
- **多衣服独立控制**：每个衣架位置可以独立控制风力

**选型思路**：
- **风扇类型**：12V DC风扇，风量80-100 CFM
- **加热元件**：PTC加热片或电阻丝，功率20-50W/个
- **布局**：进风口2个，出风口2-3个，形成循环
- **控制**：PWM调速 + 加热功率调节 + **独立控制每个位置**

**工作思路**：
- 进风口风扇引入空气
- 电阻丝加热空气
- 热空气在风干区循环
- 出风口排出湿空气
- 形成热风循环，加速干燥
- **多衣服时**：根据每件衣服的干湿程度，独立调整该位置的风力

### 2.3 紫外线消毒系统

**需求**：6-8个UV-C小灯珠

**功能**：
- 紫外线杀菌消毒
- 去除异味
- 保证衣物卫生

**选型思路**：
- **UV-C LED**：275nm波长，3W/颗
- **数量**：6-8颗，均匀分布在风干区
- **驱动**：恒流驱动模块，支持PWM调光
- **安全**：检测到人体自动关闭

**工作思路**：
- 衣物进入风干区后，开启UV-C灯
- 照射15-30分钟
- 与风机协同工作，保证均匀照射
- 完成后自动关闭

### 2.4 太阳能系统（可选）

**需求**：太阳能板，给电池充电

**功能**：
- 晴天时给电池充电
- 节能环保，体现新能源理念
- 增加比赛亮点

**实现思路**：
- **太阳能板**：10W-20W，12V输出
- **充电管理**：MPPT充电控制器或简单充电电路
- **电池**：12V锂电池或铅酸电池
- **工作模式**：
  - 有阳光时：太阳能充电，多余能量给系统供电
  - 无阳光时：电池供电或市电供电

**简化方案**（如果实现困难）：
- 只安装太阳能板，不接充电电路
- 作为装饰，体现新能源理念
- 在PPT中说明"预留太阳能接口"

### 2.5 收衣服装置（待定）

**需求**：1-2个电机或舵机

**功能**：
- 自动收衣服
- 将衣物从衣架取下
- 折叠或收纳

**实现思路**：
- **方案1**：机械臂结构
  - 舵机控制机械臂运动
  - 夹爪夹取衣物
  - 实现收衣服动作
  
- **方案2**：旋转+升降结构
  - 电机控制旋转
  - 电机控制升降
  - 配合收衣服机构

**技术难点**：
- 需要精确控制
- 需要识别衣物位置
- 需要避免衣物损坏

**建议**：
- 先实现基础功能（运送+风干）
- 收衣服功能作为扩展，后续添加
- 如果时间紧张，可以先做演示动画

## 三、系统架构设计

### 3.1 整体结构

```
┌─────────────────────────────────────┐
│  晾晒区（日常晾晒）                  │
│  [衣架1] [衣架2] [衣架3] ...        │
│         ↓ 电机1运送                  │
├─────────────────────────────────────┤
│  风干区（风干+消毒）                 │
│  ┌─────────────────────────────┐   │
│  │ 进风口风扇×2 + 加热          │   │
│  │ UV-C LED×6-8                │   │
│  │ [衣架]（电机2控制位置）      │   │
│  │ 出风口风扇×2-3               │   │
│  └─────────────────────────────┘   │
│         ↑ 电机1返回                  │
└─────────────────────────────────────┘
```

### 3.2 工作流程设计（完整方案）

**双模式工作流程**：

**模式1：自然晾晒**（晴天）

**步骤1：挂衣服**
- 用户在晾晒区或风干区挂衣服
- 系统检测到新衣物（重量传感器）

**步骤2：获取天气数据**
- WiFi模块连接天气API
- 获取当天天气数据（晴天/阴天/雨天、温度、湿度）

**步骤3：AI模式推荐**
- 根据天气数据，AI推荐模式：
  - 晴天+温度>20°C+湿度<70% → 推荐"自然晾晒"
  - 阴天/雨天+湿度>70% → 推荐"热风烘干"
- 用户确认或自动选择

**步骤4：移动到晾晒区**
- 如果衣服在风干区，步进电机工作，移到晾晒区
- 限位开关检测到位

**步骤5：自然晾晒**
- 开始计时晾晒
- 用户可以手动选择"完成"
- 或系统定时完成（如2-4小时）

**步骤6：检测天气变化**
- 如果天气变坏（下雨），自动切换到风干模式
- 步进电机工作，移到风干区

**模式2：热风烘干**（阴雨天）

**步骤1-3**：同自然晾晒模式

**步骤4：移动到风干区**
- 如果衣服在晾晒区，步进电机工作，移到风干区
- 限位开关检测到位

**步骤5：用户选择模式**
- 快速模式（1-2小时）
- 标准模式（2-4小时）
- 轻柔模式（4-6小时）
- 消毒模式（风干+UV-C）

**步骤6：开始烘干**
- 开启对应位置的风机
- 开启加热元件
- 如果选择消毒模式，开启UV-C灯

**步骤7：AI智能判断**
- 重量传感器持续监测（每5-10分钟）
- AI分析重量变化趋势曲线
- 判断干湿程度：
  - **未干**：继续烘干，高风力（100%功率）
  - **接近干**：降低功率，低风力（20-30%功率）
  - **已干**：关闭该位置的风机

**步骤8：多衣服独立控制**
- 如果多件衣服，每件独立判断
- 每件独立控制风力
- 如果一件干了，只关闭该位置的风机

**步骤9：完成**
- 所有衣服都干了，关闭所有设备
- 提醒用户取衣服
- 记录数据，用于AI学习优化

### 4.2 AI功能设计（真正解决实际问题）

**核心AI功能1：智能干湿检测**（最重要）
- **功能**：自动检测衣服干了没有，不需要用户判断
- **实现**：
  - **重量传感器**（主要）：每个衣架位置一个，持续监测衣物重量变化
  - **AI算法**：
    - 分析重量变化趋势曲线（快速下降期→缓慢下降期→稳定期）
    - 使用预先训练好的模型判断是否干燥
    - 或使用简单规则+学习优化（重量稳定+下降速度<阈值）
  - **多衣服独立控制**：
    - 每个衣架位置独立重量传感器
    - 每个位置独立AI判断
    - 根据每件衣服的干湿程度，独立调整该位置的风力
- **价值**：用户不需要用手摸，不需要猜测，真正解决痛点
- **优势**：
  - 解决了湿度传感器位置和干扰问题
  - 多衣服独立控制，精准高效
  - AI可以学习优化，越用越智能

**核心AI功能2：智能模式推荐**
- **功能**：根据衣物情况、天气情况，智能推荐最佳模式
- **实现**：
  - 用户手动输入衣物类型（或RFID标签识别）
  - 根据衣物类型推荐模式
  - 根据天气API推荐操作
  - 根据用户历史习惯学习优化
- **价值**：用户不需要思考，系统自动推荐
- **优势**：简单实用，可以学习用户习惯

**核心AI功能3：智能天气分析**
- **功能**：根据天气API，智能推荐晾晒或风干
- **实现**：
  - 获取当天天气数据
  - AI决策：晴天+温度高 → 推荐自然晾晒（省电）
  - 阴天+湿度高 → 推荐快速风干
- **价值**：帮助用户决策，节能省电
- **优势**：技术简单，实用价值高

**核心AI功能4：智能学习优化**
- **功能**：学习用户使用习惯，自动优化参数
- **实现**：
  - 记录用户选择的模式
  - 记录实际完成时间
  - AI学习分析，优化推荐算法
- **价值**：越用越智能，提升体验
- **优势**：个性化，技术可行

**核心AI功能5：智能节能控制**
- **功能**：智能控制，自动节能
- **实现**：
  - 检测到衣服已经干了 → 自动关闭
  - 检测到用户不在 → 降低功率或关闭
  - 检测到天气变好 → 推荐切换到晾晒模式
- **价值**：自动控制，节能省电，降低使用成本
- **优势**：技术简单，实用价值高

**不推荐的AI功能**：
- ❌ **图像识别衣物类型**：技术难度高，价值有限，难以识别多件衣服
- ❌ **图像识别材质**：准确率低，用户手动选择也不麻烦

**AI功能定位**：
- **不是**：为了AI而AI，展示技术
- **而是**：真正解决用户痛点，提升体验

## 五、控制系统设计

### 5.1 主控制器

**STM32F407VGT6**：
- 控制2个步进电机
- 控制4-5个风扇和加热
- 控制6-8个UV-C LED
- 处理传感器数据
- 实现工作流程控制

### 5.2 传感器系统

**位置检测**：
- 限位开关：检测起始和终止位置
- 编码器（可选）：精确位置反馈

**环境监测**：
- **重量传感器**（核心）：每个衣架位置一个，检测衣物重量变化，判断干湿程度
  - 优势：整体检测（不受位置影响），不受热风干扰，准确可靠
- **湿度传感器**（辅助）：风干区整体1个，检测环境湿度，用于模式推荐和功率调整
  - 注意：不用于判断单件衣服是否干了（受位置和热风干扰影响大）
- 光照传感器：监测晾晒区光照（晾晒强化用）

**AI智能检测**：
- **主要依靠重量传感器**：检测整个衣物重量，判断干湿程度
- **湿度传感器辅助**：只用于环境监测和功率调整，不用于干湿判断
- AI算法判断干湿程度，自动判断完成时间

**安全检测**：
- 人体感应：检测到人体自动关闭UV-C
- 门检测：开门自动停止运动

### 5.3 通信系统

**WiFi模块（ESP8266）**：
- 连接天气API
- 手机APP控制
- 数据上传云端

**串口屏**：
- 显示工作状态
- 触摸操作
- 参数设置

## 六、结构设计思路

### 6.1 丝杠传动设计

**水平移动（晾晒区↔风干区）**：
- 丝杠：1605或2005（根据距离选择）
- 电机：45步进电机
- 导轨：直线导轨（保证平稳）
- 限位：两端限位开关

**垂直移动（风干区定位）**：
- 可选：如果需要多排衣架
- 丝杠：垂直安装
- 电机：45步进电机

### 6.2 风道设计

**进风口**：
- 位置：风干区底部或侧面
- 数量：2个风扇
- 功能：引入空气 + 加热

**出风口**：
- 位置：风干区顶部
- 数量：2-3个风扇
- 功能：排出湿空气

**气流循环**：
- 底部进风 → 加热 → 向上流动 → 顶部出风
- 形成循环，保证均匀

### 6.3 衣架固定设计

**思路1：挂钩式**
- 衣架挂在移动平台上
- 平台沿丝杠移动
- 简单可靠

**思路2：夹持式**
- 机械夹持衣架
- 可以旋转
- 适合收衣服功能

## 八、AI功能实现思路

### 8.1 图像识别（衣物识别）

**硬件**：
- ESP32-CAM摄像头模块
- 或USB摄像头 + 上位机处理

**功能**：
- 识别衣物类型（T恤、裤子、外套等）
- 识别材质（棉、化纤、丝绸等）
- 识别干湿程度

**实现思路**：
- 使用TensorFlow Lite（离线）
- 或对接云端API（需要网络）
- 识别后自动选择风干参数

### 8.2 智能决策

**天气分析**：

## 十二、核心竞争优势分析

### 12.1 vs 烘洗一体机：三大核心竞争优势

**1. 价格优势**（最重要）
- **烘洗一体机**：3000-10000元
- **智能晾衣架**：500-900元
- **优势**：价格只有1/10-1/5，适合预算有限用户

**2. 空间优势**
- **烘洗一体机**：需要地面空间（60×60×85cm），需要上下水
- **智能晾衣架**：可以挂墙上或阳台，不占地面空间，不需要上下水
- **优势**：适合小户型、租房、宿舍

**3. 护衣优势**
- **烘洗一体机**：高温烘干（60-80°C），容易损伤衣物
- **智能晾衣架**：低温风干（30-50°C），不伤衣物
- **优势**：保持柔软，适合精细衣物（丝绸、羊毛）

### 12.2 次要竞争优势

**4. 容量优势**：可以同时晾晒10-20件，不受重量限制
**5. 节能优势**：耗电量200-400W（vs 1000-2000W），可以太阳能供电
**6. 使用场景优势**：灵活使用，可以随时挂取，适合手洗用户
**7. 功能扩展优势**：紫外线消毒、AI识别、太阳能供电

### 12.3 目标用户

**核心目标用户**：
- ✅ **预算有限用户**：学生、租房族、小家庭（买不起烘洗一体机）
- ✅ **空间受限用户**：小户型、租房、宿舍（没有地方放烘洗一体机）
- ✅ **护衣需求用户**：注重衣物保养，有精细衣物（不想高温烘干）

**次要目标用户**：
- ✅ **节能环保用户**：注重节能，电费敏感
- ✅ **手洗用户**：手洗衣服，不需要洗烘一体

### 12.4 市场定位

**定位**：烘洗一体机的**补充**或**替代方案**

**策略**：
- **不是**：和烘洗一体机正面竞争
- **而是**：找到烘洗一体机**覆盖不到的市场**
- **提供**：**性价比更高**的解决方案
