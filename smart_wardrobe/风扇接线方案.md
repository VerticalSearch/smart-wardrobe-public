# 3个12V/50W风扇接线方案

## 一、系统参数

### 电池规格
- **标称电压**：11.1V（3S锂电池）
- **满电电压**：12.6V（4.2V × 3）
- **容量**：5300mAh = 5.3Ah
- **放电倍率**：45C
- **最大放电电流**：5.3Ah × 45C = 238.5A（理论值）

### 风扇规格
- **单个功率**：50W
- **工作电压**：12V
- **数量**：3个
- **总功率**：150W
- **理论电流**：150W ÷ 12V = 12.5A

## 二、接线方案

### 2.1 基本并联接线（推荐）

```
电池正极(+) 
    │
    ├───[保险丝 15A]───[开关]───┬─── 风扇1正极(+)
    │                            ├─── 风扇2正极(+)
    │                            └─── 风扇3正极(+)
    │
电池负极(-)
    │
    ├───────────────────────────┬─── 风扇1负极(-)
    │                           ├─── 风扇2负极(-)
    │                           └─── 风扇3负极(-)
```

### 2.2 详细接线步骤

**步骤1：准备材料**
- 3个12V/50W风扇
- 11.1V锂电池（带XT60或T插头）
- 15A保险丝 + 保险丝座
- 开关（15A以上）
- 导线（推荐16AWG或1.5mm²，至少能承受15A）
- 接线端子（可选，方便连接）

**步骤2：连接电池正极**
1. 从电池正极引出主电源线（红色，16AWG）
2. 串联保险丝（15A，防止过流）
3. 串联开关（方便控制）
4. 分出3路，分别连接到3个风扇的正极

**步骤3：连接电池负极**
1. 从电池负极引出公共地线（黑色，16AWG）
2. 分出3路，分别连接到3个风扇的负极

**步骤4：检查**
- 确认所有连接牢固
- 确认正负极正确（风扇有正负极标识）
- 确认保险丝已安装
- 确认开关处于关闭状态

## 三、电流计算与线材选择

### 3.1 电流计算

**理论电流**：
- 单个风扇：50W ÷ 12V = 4.17A
- 3个风扇并联：4.17A × 3 = 12.5A

**实际考虑**：
- 启动电流：风扇启动时电流可能达到额定电流的2-3倍（约25-37.5A）
- 效率损失：实际电流可能略高于理论值
- **建议按15-20A设计**

### 3.2 线材选择

| 电流 | 推荐线径 | AWG规格 | 说明 |
|------|---------|---------|------|
| 12.5A | 1.5mm² | 16AWG | 基本够用 |
| 15A | 2.5mm² | 14AWG | **推荐** |
| 20A | 4mm² | 12AWG | 更安全 |

**推荐**：使用**14AWG（2.5mm²）**导线，留有余量。

### 3.3 保险丝选择

- **额定电流**：15A（略大于工作电流12.5A）
- **类型**：快熔保险丝（防止启动电流误触发）
- **位置**：电池正极输出端

## 四、保护措施

### 4.1 必须的保护

1. **保险丝**：15A快熔保险丝，防止过流
2. **开关**：15A以上开关，方便控制
3. **电压监控**：建议添加电压表，监控电池电压

### 4.2 可选保护（推荐）

1. **欠压保护**：
   - 当电池电压低于9.9V（单节3.3V）时，自动切断电源
   - 防止电池过放，延长电池寿命

2. **过流保护**：
   - 电流超过20A时，自动切断电源
   - 防止短路或故障

3. **温度保护**：
   - 监测电池温度，超过60°C时切断电源

## 六、注意事项

### 6.1 安全注意事项

⚠️ **重要**：
1. **确认正负极**：风扇有正负极标识，接反会损坏风扇
2. **先接负极**：先连接所有负极，再连接正极，避免短路
3. **检查连接**：所有连接必须牢固，避免接触不良发热
4. **使用保险丝**：必须安装保险丝，防止过流损坏电池
5. **电池保护**：不要将电池放电到单节低于3.0V

### 6.2 电压匹配

- **电池满电**：12.6V（可以正常驱动12V风扇）
- **电池标称**：11.1V（略低于12V，风扇转速可能略慢）
- **电池低电压**：<10V（建议停止使用，保护电池）

**建议**：
- 如果风扇转速不够，可以考虑使用DC-DC升压模块，稳定输出12V
- 或者使用4S电池（14.8V），通过降压模块降到12V

### 6.3 电流限制

- **工作电流**：约12.5A（3个风扇同时工作）
- **启动电流**：可能达到25-37.5A（瞬间）
- **电池最大电流**：238.5A（45C放电倍率，足够）

**结论**：电池容量和放电倍率完全满足需求。

## 七、测试步骤

### 7.1 上电前检查

1. ✅ 确认所有连接正确
2. ✅ 确认保险丝已安装
3. ✅ 确认开关处于关闭状态
4. ✅ 确认电池电压正常（11.1V-12.6V）
5. ✅ 确认导线规格足够（14AWG以上）

### 7.2 上电测试

1. **单风扇测试**：
   - 先只连接1个风扇
   - 打开开关，观察风扇是否正常转动
   - 测量实际电流（应约4-5A）

2. **双风扇测试**：
   - 连接2个风扇
   - 打开开关，观察两个风扇是否正常
   - 测量实际电流（应约8-10A）

3. **三风扇测试**：
   - 连接3个风扇
   - 打开开关，观察所有风扇是否正常
   - 测量实际电流（应约12-15A）

### 7.3 长时间测试

- 运行10-20分钟，观察：
  - 电池电压下降速度
  - 导线是否发热
  - 连接点是否松动
  - 风扇是否正常工作

## 八、常见问题

### Q1: 风扇不转怎么办？
- 检查正负极是否正确
- 检查保险丝是否熔断
- 检查开关是否打开
- 检查电池电压是否足够

### Q2: 风扇转速慢怎么办？
- 检查电池电压（可能电压过低）
- 检查导线是否过细（压降过大）
- 检查连接是否牢固（接触电阻）

### Q3: 保险丝频繁熔断怎么办？
- 检查是否有短路
- 检查保险丝规格是否合适（15A快熔）
- 检查启动电流是否过大

### Q4: 电池发热怎么办？
- 立即停止使用
- 检查是否有短路
- 检查电流是否过大
- 检查电池是否损坏

## 十、总结

**接线方式**：3个风扇**并联**连接，正极接正极，负极接负极。

**关键参数**：
- 工作电流：约12.5A
- 推荐线径：14AWG（2.5mm²）
- 保险丝：15A快熔
- 开关：15A以上

**预计运行时间**：约18-22分钟（根据之前计算）
