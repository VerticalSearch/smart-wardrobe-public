# 智能晾衣架系统

## 项目简介

基于STM32F407VGT6的智能晾衣架系统，实现双模式智能晾干：晴天自然晾晒（节能），阴雨天热风烘干（快速）。

## 核心功能

1. **双模式设计**：晴天自然晾晒（节能），阴雨天热风烘干（快速）
2. **AI智能判断**：神经网络分析重量变化趋势，自动判断是否干燥
3. **多衣服独立控制**：每件衣服独立判断和控制，精准高效
4. **自动切换**：根据天气自动选择模式，智能决策

## 工作流程

```
用户挂衣服 → 获取天气数据 → AI模式推荐：
  ├── 晴天 → 自然晾晒（节能）
  └── 阴雨天 → 热风烘干（快速）→ AI判断完成
```

## 硬件架构

- **主控**：STM32F407VGT6
- **步进电机**：45步进电机×2（控制衣物在晾晒区和风干区之间移动）
- **风机系统**：12V DC风扇×5 + PTC加热片×5（支持独立控制）
- **传感器**：重量传感器（每个衣架位置×1）、湿度传感器（风干区×1）
- **显示**：4.3寸串口屏
- **通信**：ESP8266 WiFi模块（天气API）
