# 智能晾衣架完整实施方案

## 一、系统概述

### 1.1 核心功能

**双模式智能晾衣架系统**：
- **模式1：自然晾晒**（晴天）
  - 步进电机将衣物移到室外晾晒区
  - 利用自然阳光和风晾干
  - 节能省电

- **模式2：热风烘干**（阴雨天）
  - 在室内风干区进行热风烘干
  - 快速晾干，不受天气影响

### 1.2 工作流程

```
用户挂衣服 → 系统检测天气 → 选择模式：
  ├── 晴天 → 步进电机移到室外晾晒区 → 自然晾晒
  └── 阴雨天 → 留在室内风干区 → 热风烘干 → AI判断完成
```

## 二、硬件架构

### 2.1 步进电机系统

**功能**：控制衣物在晾晒区和风干区之间移动

**配置**：
- **步进电机×2**：45步进电机
  - 电机1：水平移动（晾晒区↔风干区）
  - 电机2：垂直移动（可选，用于多排衣架）
- **驱动模块×2**：A4988或DRV8825
- **丝杠+导轨×2**：1605或2005规格
- **限位开关×4**：检测起始和终止位置

### 2.2 风机系统

**功能**：提供热风循环，加速干燥

**配置**：
- **风扇×5**：12V DC风扇，80-100 CFM
  - 进风口风扇×2：引入空气
  - 出风口风扇×2-3：排出湿空气
- **加热元件×5**：PTC加热片，20-50W/个
- **独立控制**：每个衣架位置可以独立控制风力（多衣服时）

**布局**：
- 每个衣架位置对应一个独立的风机控制
- 可以根据每件衣服的干湿程度，独立调整风力

### 2.3 传感器系统

**重量传感器**（核心）：
- **数量**：每个衣架位置×1
- **功能**：检测衣物重量变化，判断干湿程度
- **精度**：0.1-0.5g
- **量程**：0-5kg

**湿度传感器**（辅助）：
- **数量**：风干区整体×1
- **功能**：检测环境湿度，用于模式推荐和功率调整
- **注意**：不用于判断单件衣服是否干了

**天气传感器/API**：
- **WiFi模块**（ESP8266）：连接天气API
- **功能**：获取天气数据，判断是否适合晾晒

### 2.4 控制系统

**主控制器**：STM32F407VGT6
- 控制步进电机
- 控制风机和加热
- 处理传感器数据
- 实现AI算法

**显示**：4.3寸串口屏
- 显示工作状态
- 触摸操作
- 参数设置

## 三、工作模式设计

### 3.1 模式1：自然晾晒（晴天）

**触发条件**：
- 天气API显示：晴天+温度>20°C+湿度<70%
- 或用户手动选择"自然晾晒"模式

**工作流程**：
1. 用户挂衣服（在晾晒区或风干区）
2. 系统检测到新衣物（重量传感器）
3. 系统获取天气数据
4. 判断适合自然晾晒
5. 步进电机工作，将衣物移到室外晾晒区
6. 开始计时晾晒
7. 用户可以手动选择"完成"或系统定时完成

**优势**：
- 节能省电（不需要风机和加热）
- 自然晾晒，不伤衣物
- 适合晴天使用

**注意事项**：
- 需要检测天气变化，如果变天可以自动切换到风干模式
- 需要检测用户是否取走衣服

### 3.2 模式2：热风烘干（阴雨天）

**触发条件**：
- 天气API显示：阴天/雨天+湿度>70%
- 或用户手动选择"快速烘干"模式

**工作流程**：
1. 用户挂衣服（在晾晒区或风干区）
2. 系统检测到新衣物（重量传感器）
3. 系统获取天气数据
4. 判断需要热风烘干
5. 如果衣服在晾晒区，步进电机工作，移到风干区
6. 用户选择模式（快速/标准/轻柔/消毒）
7. 开启风机和加热
8. **AI智能判断**：重量传感器持续监测，AI判断是否干了
9. 达到阈值，自动完成
10. 关闭所有设备，提醒用户

**优势**：
- 快速晾干（1-2小时）
- 不受天气影响
- AI智能判断，自动完成

## 四、AI智能判断方案

### 4.1 核心思路

**AI功能**：根据重量传感器数据，判断衣服是否干燥

**实现方式**：
1. **数据采集**：重量传感器持续采集数据
2. **趋势分析**：分析重量变化趋势曲线
3. **AI判断**：使用预先训练好的模型，判断是否干燥
4. **多衣服控制**：根据每件衣服的干湿程度，独立调整风力

### 4.2 重量变化趋势曲线

**曲线特征**：

**阶段1：快速下降期**（湿衣服）
- **特征**：重量快速下降（水分快速蒸发）
- **时间**：前30-60分钟
- **下降速度**：>2%/10分钟
- **判断**：衣服还很湿，需要继续烘干

**阶段2：缓慢下降期**（半干）
- **特征**：重量下降速度变慢
- **时间**：60-90分钟
- **下降速度**：0.5-2%/10分钟
- **判断**：衣服半干，接近完成

**阶段3：稳定期**（接近干）
- **特征**：重量不再明显下降，稳定在干重附近
- **时间**：90分钟以后
- **下降速度**：<0.5%/10分钟
- **判断**：衣服接近干了，可以判断完成

**曲线模型**：
- 可以使用指数衰减模型：W(t) = W0 × e^(-kt)
- 或使用分段线性模型：不同阶段用不同的线性函数

### 4.3 AI模型训练

**训练数据收集**：
- 收集大量不同材质、不同重量的衣物烘干数据
- 记录：时间、重量、材质、最终状态（干了/没干）
- 建立数据集

**模型选择**：
- **方案1**：简单的机器学习模型（推荐）
  - 决策树、随机森林
  - 特征：当前重量、下降速度、稳定性、已烘干时间
  - 输出：是否干了（二分类）

- **方案2**：时间序列预测模型
  - LSTM、GRU
  - 输入：历史重量数据序列
  - 输出：预测完成时间或是否干了

- **方案3**：规则+学习混合模型（推荐）
  - 基础规则：重量稳定+下降速度<阈值
  - 学习优化：根据历史数据优化阈值

**模型训练**：
- 使用收集的数据训练模型
- 验证准确率
- 部署到STM32（如果模型简单）或云端（如果模型复杂）

### 4.4 AI判断流程

**实时判断**：
1. **数据采集**：每5-10分钟采集一次重量数据
2. **特征提取**：
   - 当前重量值（相对初始重量）
   - 重量下降速度（过去10分钟的变化率）
   - 重量稳定性（过去10分钟的标准差）
   - 已烘干时间
   - 重量变化趋势（上升/下降/稳定）

3. **AI判断**：
   - 输入特征到AI模型
   - 模型输出：是否干了（概率或二分类）
   - 或输出：预测完成时间

4. **结果输出**：
   - **未干**：继续烘干
   - **接近干**：降低功率，继续烘干
   - **已干**：自动完成，关闭设备

### 4.5 多衣服独立控制

**问题**：多件衣服同时烘干，每件衣服的干湿程度不同

**解决方案**：每个衣架位置独立控制

**控制策略**：
- **独立检测**：每个衣架位置独立重量传感器
- **独立判断**：每件衣服独立AI判断
- **独立控制**：每个衣架位置对应独立的风机控制

**风力调控**：
- **未干**：高风力（100%功率）
- **半干**：中风力（50-70%功率）
- **接近干**：低风力（20-30%功率）
- **已干**：关闭该位置的风机

**实现方式**：
- 每个衣架位置对应一个独立的风机控制模块
- 根据该位置衣物的干湿程度，独立调整风力
- 如果一件衣服干了，只关闭该位置的风机，不影响其他

**优势**：
- 精准控制：每件衣服独立控制
- 节能省电：干了就关闭，不浪费电
- 提高效率：不同干湿程度的衣服可以同时处理

## 五、完整工作流程

### 5.1 挂衣服阶段

**步骤1**：用户挂衣服
- 在晾晒区或风干区挂衣服
- 系统检测到新衣物（重量传感器检测到重量增加）

**步骤2**：记录初始数据
- 记录初始重量
- 记录挂衣服时间
- 记录衣架位置

### 5.2 模式选择阶段

**步骤3**：获取天气数据
- WiFi模块连接天气API
- 获取当天天气数据（晴天/阴天/雨天、温度、湿度）

**步骤4**：AI模式推荐
- 根据天气数据，AI推荐模式：
  - 晴天+温度>20°C+湿度<70% → 推荐"自然晾晒"
  - 阴天/雨天+湿度>70% → 推荐"热风烘干"
- 用户确认或自动选择

### 5.3 自然晾晒模式

**步骤5**：移动到晾晒区
- 如果衣服在风干区，步进电机工作，移到晾晒区
- 限位开关检测到位

**步骤6**：自然晾晒
- 开始计时
- 用户可以手动选择"完成"
- 或系统定时完成（如2-4小时）

**步骤7**：检测天气变化
- 如果天气变坏（下雨），自动切换到风干模式
- 步进电机工作，移到风干区

### 5.4 热风烘干模式

**步骤5**：移动到风干区
- 如果衣服在晾晒区，步进电机工作，移到风干区
- 限位开关检测到位

**步骤6**：用户选择模式
- 快速模式（1-2小时）
- 标准模式（2-4小时）
- 轻柔模式（4-6小时）
- 消毒模式（风干+UV-C）

**步骤7**：开始烘干
- 开启对应位置的风机
- 开启加热元件
- 如果选择消毒模式，开启UV-C灯

**步骤8**：AI智能判断
- 重量传感器持续监测（每5-10分钟）
- AI分析重量变化趋势
- 判断干湿程度：
  - **未干**：继续烘干，高风力
  - **接近干**：降低功率，低风力
  - **已干**：关闭该位置的风机

**步骤9**：多衣服独立控制
- 如果多件衣服，每件独立判断
- 每件独立控制风力
- 如果一件干了，只关闭该位置的风机

**步骤10**：完成
- 所有衣服都干了，关闭所有设备
- 提醒用户取衣服
- 记录数据，用于AI学习优化

## 六、AI模型实现方案

### 6.1 方案1：简单规则+学习优化（推荐）

**基础规则**：
- 重量稳定（10分钟内变化<2%）
- 重量下降速度<0.5%/10分钟
- 相对重量<1.1（当前重量/初始重量）
- 已烘干时间>60分钟

**学习优化**：
- 记录每次烘干的数据
- 记录用户反馈（干了/没干）
- 根据反馈调整阈值
- 学习不同材质的最佳阈值

**优势**：
- 简单可靠，不需要复杂的AI模型
- 可以部署到STM32
- 容易调试和维护

### 6.2 方案2：机器学习模型

**模型选择**：
- 决策树或随机森林
- 特征：当前重量、下降速度、稳定性、已烘干时间、材质
- 输出：是否干了（二分类）

**训练数据**：
- 收集大量烘干数据
- 标注：干了/没干
- 训练模型

**部署**：
- 如果模型简单，可以部署到STM32
- 如果模型复杂，可以部署到云端，STM32调用API

**优势**：
- 更智能，可以学习复杂的模式
- 准确率可能更高

### 6.3 方案3：时间序列预测

**模型选择**：
- LSTM或GRU
- 输入：历史重量数据序列（如过去30分钟的数据）
- 输出：预测完成时间或是否干了

**训练数据**：
- 收集大量时间序列数据
- 标注：完成时间或最终状态

**部署**：
- 通常需要部署到云端（模型复杂）
- STM32发送数据到云端，获取预测结果

**优势**：
- 可以预测完成时间
- 更智能

**劣势**：
- 需要网络连接
- 模型复杂，成本高

### 6.4 推荐方案

**推荐**：**方案1（简单规则+学习优化）**

**理由**：
- ✅ 简单可靠，不需要复杂的AI模型
- ✅ 可以部署到STM32，不需要网络
- ✅ 容易调试和维护
- ✅ 成本低

**实现**：
- 基础规则判断
- 记录数据，学习优化阈值
- 根据材质和用户习惯，自动调整

## 七、多衣服独立控制实现

### 7.1 硬件配置

**每个衣架位置**：
- 重量传感器×1
- 独立的风机控制模块×1
- 独立的加热控制模块×1（可选）

**控制方式**：
- PWM控制风机速度
- PWM控制加热功率
- 每个位置独立控制

### 7.2 控制算法

**控制逻辑**：
```
for 每个衣架位置:
    读取重量传感器数据
    AI判断干湿程度
    if 未干:
        设置风力 = 100%
    elif 接近干:
        设置风力 = 30%
    elif 已干:
        设置风力 = 0%（关闭）
    
    控制该位置的风机功率
```

### 7.3 控制优势

**精准控制**：
- 每件衣服独立控制
- 根据干湿程度调整风力
- 干了就关闭，不浪费电

**节能省电**：
- 如果一件衣服干了，只关闭该位置的风机
- 其他衣服继续烘干
- 整体节能

**提高效率**：
- 不同干湿程度的衣服可以同时处理
- 不需要等待所有衣服都干
