# 项目总览

本文件夹已按用途做了基础整理，当前主线是“智能衣橱”。

## 建议优先查看

1. `01_智能衣橱方案/`
   - 智能衣橱方案文档与汇总材料。
   - 入口文件：`智能衣橱系统总览与执行流程.md`
   - 当前落地基线：树莓派触摸屏网页 + 树莓派外接摄像头 + 云端后端 + 双 STM32F407。

2. `02_界面原型/`
   - 可在树莓派触摸屏浏览器中运行的网页界面、云端控制台、任务控制页和配套界面草图。
   - 入口文件：`ui_prototype.html`

3. `代码/4.11/`
   - 当前最贴近智能衣橱落地的双主板固件工程。
   - `主板1`：协调板，负责树莓派串口、板间串口、OLED、按键、除湿袋重力、温湿度和挂位限位开关等接口；串口屏相关接口仅作为历史/调试保留。
   - `主板2`：执行板，负责多路步进电机、伸缩轴、舵机、按键测试和回零。

4. `artifacts/`
   - 当前调试过程产物。
   - 包含历史 K230 调试产物、原型截图备份和过程验证资料。

## 当前方案口径

- 当前主线：树莓派触摸屏网页 + 树莓派外接摄像头 + App/Web + 云端后端 + STM32F407 主板1 + STM32F407 主板2。
- 树莓派连接可交互触摸屏，在本地浏览器中直接运行网页界面，是现场主 HMI；网页点击后先到云端，再由云端驱动硬件侧整条链路。
- 树莓派负责摄像头接入、拍照上传、网页承载以及与主板1的串口桥接。
- 主板1负责流程协调、传感器数据汇聚和任务判定，不直接承担所有运动执行。
- 主板2负责运动执行，不处理视觉、联网和云端接口。
- 串口屏资料仅作为历史界面和旧调试方案参考，不再作为当前运行方案的一部分来描述。
- RFID/NFC、`tag_id`、`slot_id` 属于后续库存一致性增强，不是当前代码已经闭环的主流程。

## 当前整理原则

- 不改动现有固件工程结构。
- 只整理顶层散落文件，方便快速定位主线内容。
- 与同一页面/工具相关的文件尽量放在同一目录。
